# Appothek Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the InkTap repo into Appothek, a multi-tool Android app that ships InkTap and the ported Buchstabierer as
tools, replaces the Buchstabierer Play listing (same app ID and key) and releases a signed APK and AAB from GitHub.

**Architecture:** Gradle multi-module: `:app` (shell: start screen, settings sheet, per-tool activities, launcher
aliases, shortcuts), `:core` (Tool interface, theme, card UI pieces), `:tools:inktap`, `:tools:buchstabierer`,
`build-logic` convention plugins. Tools depend only on `:core`, never on each other.

**Tech Stack:** Kotlin 2.4, AGP 9.5, Compose BOM 2026.09 / Material 3, DataStore Preferences, JUnit 4, Python 3 for
the word-list script. GitHub Actions for CI and release.

**Spec:** `docs/superpowers/specs/2026-11-09-appothek-design.md`

## Global Constraints

- `applicationId = "bayern.kickner.buchstabierer"`, debug `applicationIdSuffix = ".debug"`.
- `minSdk = 35`, `compileSdk = 37`, `targetSdk = 37`, Java 17 bytecode, daemon JDK Corretto 25 (unchanged).
- versionName from `-PversionName`, default `1.0.0`; versionCode `major*10000 + minor*100 + patch` (must be > 11).
- No `INTERNET` permission anywhere. `android.hardware.nfc` with `required="false"`.
- Buchstabierer storage names are frozen: DataStore `settings`, SharedPreferences `settings`, all keys and value
  formats as listed in the spec. Appothek's own DataStore is `appothek`, InkTap keeps SharedPreferences `inktap`.
- Legacy launcher component name `bayern.kickner.buchstabierer.MainActivity` must exist and be the Appothek entry.
- Tool launcher aliases default `android:enabled="false"`.
- Never copy anything from the Buchstabierer repo's history, `keystore/`, or the password comment in its
  `app/build.gradle.kts`. Never commit keystores.
- Repo license Apache 2.0. UI language: German default; the Appothek shell and InkTap also ship `values-en`
  (InkTap already does), the Buchstabierer stays German-only.
- Release secrets: `APPOTHEK_KEYSTORE_BASE64`, `APPOTHEK_KEYSTORE_PASSWORD`, `APPOTHEK_KEY_ALIAS`,
  `APPOTHEK_KEY_PASSWORD`; signing env vars `APPOTHEK_KEYSTORE_FILE`, `APPOTHEK_KEYSTORE_PASSWORD`,
  `APPOTHEK_KEY_ALIAS`, `APPOTHEK_KEY_PASSWORD`.

## Review Focus

1. Existing Buchstabierer data written by version 7.0 (raw keys, `|`-separated history, `A:Wort|B:Wort` alphabet,
   favourite texts under `"<col> <row>"`) must read back unchanged → Task 4 DataStore compatibility test.
2. A device without NFC: InkTap card greyed, its alias cannot be enabled, no InkTap dynamic shortcut, and an alias
   left enabled by a backup restore gets switched off at start → Task 6 `LauncherEntriesTest` + Task 7 emulator check.
3. The same tool open in the Appothek and as its own app at once must not crash on DataStore ("multiple DataStores
   active") → Task 4 single top-level delegate + Task 7 emulator check.
4. Word list input with digits, hyphens, all-caps, lowercase words, inflected forms and blocklisted words → Task 3
   script tests.
5. Back navigation: tool opened from the grid returns to the grid; tool opened through its own activity finishes →
   Task 5/6 behaviour, verified in Task 7.

### Task 3: Word list from the Free German Dictionary

**Files:**
- Create: `tools/buchstabierer/wordlist/build_wordlist.py`, `tools/buchstabierer/wordlist/test_build_wordlist.py`,
  `tools/buchstabierer/wordlist/blocklist.txt`, `tools/buchstabierer/wordlist/SOURCE.md`
- Create (generated): `tools/buchstabierer/src/main/res/raw/words.txt`

**Interfaces:**
- Produces: `words.txt`, UTF-8, one noun per line, sorted, < 200,000 lines.
- Script: `python3 build_wordlist.py <german.dic> <blocklist.txt> <out>`; pure function
  `filter_words(words: Iterable[str], blocklist: set[str]) -> list[str]`.

Filter order: (1) only `[A-Za-zÄÖÜäöüß]`, (2) first letter uppercase and not all-uppercase, (3) length 4–12,
(4) not in blocklist (case-insensitive; a blocklist entry also removes words that start with it), (5) drop a word if
removing one suffix from `s, es, n, en, e, er, ern, em` yields a word that is still in the set after steps 1–4.

  output sorted and unique.
